# Brand assets

Icon artwork for **RootlessViPER4Android**, provided so anyone writing about or
linking to the project has something decent to use.

| File | Use |
|---|---|
| `rv4a-icon-1536.png` | Largest available. Banners, thread headers, print. |
| `rv4a-icon-1024.png` | Store listings, large web images. |
| `rv4a-icon-512.png` · `384` | Articles, forum posts, README embeds. |
| `rv4a-icon-256.png` and below | Favicons, avatars, inline thumbnails. |

**These are copyrighted — see [LICENSE](LICENSE).** The rest of this repository
is free software; the artwork is not, and the two should not be confused.

Sizes from 384 up carry a copyright notice: a corner plate on the two largest,
and a strip across the bottom below that, where a corner block would be too
small to read. **256 and below carry no notice**, since text at that scale is
illegible — they are copyrighted all the same.

Please use them unaltered. If you need a variant that isn't here, or the notice
is a problem for your layout, ask rather than editing one.
